BASIL & AMRUTHA WEDDING INVITATION

FILES
- index.html
- style.css
- script.js

ADD YOUR PHOTOS
Copy your own photos into assets/images and use these exact names:
- couple-main.jpg   (opening background)
- couple-hands.jpg  (Sharing Happiness circular photo)
- couple-1.jpg      (wedding photo and gallery)
- couple-2.jpg      (reception photo and gallery)
- couple-3.jpg      (gallery)
- couple-4.jpg      (gallery)

ADD MUSIC
Copy an MP3 file to assets/music/wedding-music.mp3

RUN
Open the folder in VS Code, then open index.html with Live Server.

MAPS
The wedding and reception buttons currently use Google Maps search links.
For an exact reception pin, replace the reception href in index.html with the venue's Google Maps share link.

NOTE
Image and music folders contain no sample media; add your own files.
